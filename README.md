# CODSOFT Java Development Internship

This repository contains the tasks completed as part of my Java Development Internship at CodSoft.

## Task 1 - Number Game

A Java-based number guessing game where the user tries to guess a randomly generated number between 1 and 100.

### Features

- Random number generation
- User input using Scanner
- Too high / too low feedback
- Limited number of attempts
- Multiple rounds
- Score calculation

### Technologies Used

- Java
- VS Code

### Concepts Used

- Random
- Scanner
- while loop
- if-else statements
- User input
- Variables
- Basic game logic
